# レギオン

国を率いて陣形を組み、土地を攻略する2人対戦カードゲーム（v0.3）。

- 遊ぶ：このリポジトリの GitHub Pages のURLをブラウザで開く
- CPUと対戦：「CPUと対戦」を選んで3か国と盟主を決め、「この3か国で出陣」
- 友だちと対戦：2人とも「友だちと対戦」を選んで3か国と盟主を決める。片方が「部屋を作る」を押し、表示された4文字の合言葉を相手に伝える。相手は合言葉を入れて「入る」
- カード一覧：`cards.html`

通信対戦は無料の公開中継サーバー（MQTT）経由でやりとりする。部屋を作った側の画面でゲームが進み、相手の画面に結果が送られる。

## v0.2 の追加ルール：謎の傭兵団

- お互い、最初の手札に「謎の傭兵団」を1枚持って始める（デッキ30枚＋1枚）
- 好きな数字・好きな国として使える
- 置く時、その土地の自分側にすでにある枚数だけ雇用料を払う（1枚目0点・2枚目1点・3枚目2点）
- 傭兵団が乗った土地を相手に攻略されたら、傭兵団は相手の手札に寝返る

## v0.3：偶数（攻略時効果）の強化

- 4 商人「調達」：山札から好きなカードを1枚手札に加え、山札を切る（人の4は他国のカードを2枚まで）
- 6 魔術師「殲滅」：相手の土地1つの相手側を、すべて墓地へ
- 8 賢者「看破」：相手の手札を見て数字を1つ選び、その数字のカードをすべて墓地へ
- ドラゴニュートの10「業火」：得点2倍の代わりに、相手のすべての土地で一番上を墓地へ
