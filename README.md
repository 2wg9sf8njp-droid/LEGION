# レギオン

国を率いて陣形を組み、土地を攻略する2人対戦カードゲーム（v0.2）。

- 遊ぶ：このリポジトリの GitHub Pages のURLをブラウザで開く
- CPUと対戦：「CPUと対戦」を選んで3か国と盟主を決め、「この3か国で出陣」
- 友だちと対戦：2人とも「友だちと対戦」を選んで3か国と盟主を決める。片方が「部屋を作る」を押し、表示された4文字の合言葉を相手に伝える。相手は合言葉を入れて「入る」
- カード一覧：`cards.html`

通信対戦は無料の公開中継サーバー（MQTT）経由でやりとりする。部屋を作った側の画面でゲームが進み、相手の画面に結果が送られる。

## v0.2 の追加ルール：謎の傭兵団

- お互い、最初の手札に「謎の傭兵団」を1枚持って始める（デッキ30枚＋1枚）
- 好きな数字・好きな国として使える
- 置く時、その土地の自分側にすでにある枚数だけ点を払う（1枚目0点・2枚目1点・3枚目2点）
- 傭兵団が乗った土地を相手に攻略されたら、傭兵団は相手の手札に寝返る
