# レギオン

国を率いて陣形を組み、土地を攻略する2人対戦カードゲーム（v0.1）。

- 遊ぶ：このリポジトリの GitHub Pages のURLをブラウザで開く
- CPUと対戦：「CPUと対戦」を選んで3か国と盟主を決め、「この3か国で出陣」
- 友だちと対戦：2人とも「友だちと対戦」を選んで3か国と盟主を決める。片方が「部屋を作る」を押し、表示された4文字の合言葉を相手に伝える。相手は合言葉を入れて「入る」
- カード一覧：`cards.html`

通信対戦はブラウザ同士を直接つなぐ方式（PeerJS の無料公開サーバーで相手を探す）。部屋を作った側の画面でゲームが進み、相手の画面に結果が送られる。
